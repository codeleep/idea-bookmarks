# 多组书签与共享 Markdown 描述

## 1. 使用方式

从版本 `262.11879.100.3` 开始，行书签和文件书签都支持同时加入多个组。

1. 选中一个书签，点击“管理所属分组…”。编辑器、侧栏右键和 Find Action 也提供该动作。
2. 在树中勾选需要的组，点击“保存分组”。
3. 父组和子组独立勾选，选中父组不会自动选中子组。
4. 同一书签在各组共享 Markdown 原文、编辑页和助记符。代码行位置变化时，各组同时更新。

所属分组至少保留一个；清空引用请使用删除动作。

## 2. 删除规则

删除行为取决于实际引用数量。

| 情况或选择 | 行为 |
|---|---|
| 只有一个组引用 | 直接删除书签，不弹出范围提示 |
| 多组引用，选择“仅从当前组移除” | 只移除当前组中的引用，其他组及共享描述保留 |
| 多组引用，选择“彻底删除（所有组）” | 从所有组移除，删除助记符和侧栏行标记 |
| 选择“取消”或按 Esc | 保留全部引用 |
| 批量选择书签 | 有多组引用时提示范围，“仅从所选组移除”只处理选中的引用 |
| 删除分组或分组子树 | 移除被删分组中的引用，其他组中的同一书签保留 |

## 3. 描述与旧数据

各组打开同一个书签时使用同一个 Markdown 编辑缓冲区。在任一组编辑后，所有组的描述同步更新；移除部分引用后，编辑页继续绑定剩余引用。最后一个引用删除后，旧编辑缓冲区不能重新创建已删除书签。

旧版文件书签可能在不同组中具有不同的描述。升级读取这类数据时，会按原分组标注并合并不同文本，保留原文；原本一致的描述保持原样。再次保存和恢复不重复追加。行书签在旧版中只有一个所属组，原有描述保持原样。

## 4. 验证入口

本地验证命令如下。

```bash
python3 tools/build.py --idea-home "/你的路径/IntelliJ IDEA.app"
python3 tools/runtime_smoke.py --idea-home "/你的路径/IntelliJ IDEA.app"
```

运行检查覆盖多层分组的多组归属、独立复选框及渲染、共享原生 Markdown 文档、从部分组移除、最后一个引用直接删除、所有组删除、行位置变化、XML 恢复和不同旧描述的无损合并。GUI 观测记录见 `docs/evidence/gui-multigroup-validation.json`。

## 5. 格式 2 与 Git 分支

版本 `.4` 将组内书签副本改为独立书签记录与 ID 引用；旧数据自动迁移。Git 分支沿用原版上下文机制，新适配器完整恢复层级、共享描述与引用。详见 [存储说明](STORAGE.md) 和 [AI 整理指南](AI_BOOKMARKS.md)。
